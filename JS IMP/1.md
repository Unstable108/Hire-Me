   2. The Accumulator: "The reduce method starts with an empty array [] as the initial accumulator (ans)."
   3. The Base Case vs. Recursive Step: "For each element, we check if it is an array using Array.isArray():
   * If it is a primitive value, we simply concatenate it to our running accumulator.
      * If it is a nested array, we recursively call flattenArray on that sub-array first, flatten it completely, and then concatenate the result." [4, 5, 6]

## Time and Space Complexity
Interviewers will always ask for performance metrics. Here is how to break it down accurately:
## Time Complexity: $O(N \cdot D)$ or O(N²) in the worst case  

* N is the total number of individual elements (including primitives and sub-arrays) across all levels.
* D is the maximum depth of the nesting.
* Why? The engine must visit every single element once. However, ans.concat() is not an O(1) operation; it creates a brand-new array copy every time it runs. If the array is heavily nested, copying large chunks repeatedly adds up.

## Space Complexity: O(N + D) 

* Call Stack Space (O(D)): The computer memory keeps track of each nested layer. If an array is nested 5 layers deep, there will be 5 functions paused on the call stack simultaneously.
* Output Space (O(N)): The final flattened array stores all N elements.

## Potential Follow-up Interview Questions
Be prepared for the interviewer to push your solution further. They will likely ask:  
## 1. "How can you optimize the time complexity to a strict O(N)?"

* The Issue: .concat() creates a new array every time, causing slow performance.
* The Fix: Use .push() or .push(...spread) with a helper function to mutate a single shared array, avoiding continuous array copying. 

```
function flattenArray(arr) {
  const result = [];
  function impl(target) {
    for (const element of target) {
      if (Array.isArray(element)) { impl(element); } 
      else { result.push(element); }
    }
  }
  impl(arr);
  return result;
}
```
## 2. "What happens if the array is nested 20,000 layers deep?"

* The Answer: It will throw a RangeError: Maximum call stack size exceeded.
* The Fix: You must convert the recursive approach into an iterative approach using a Stack data structure loop to keep memory on the heap instead of the call stack. 

```
function flattenIterative(arr) {
  const stack = [...arr];
  const res = [];
  while (stack.length) {
    const next = stack.pop();
    if (Array.isArray(next)) { stack.push(...next); } 
    else { res.unshift(next); }
  }
  return res;
}
```
## 3. "How would you modify this to support a specific depth limit (like arr.flat(depth))?" 

* The Fix: Add a depth tracking integer parameter to your function. Decrement it on each recursive call, and stop flattening once it hits zero.
